1. PrepSystem.gd — class_name PrepSystem, extends RefCounted. Pure logic, engine-free:
   - static orientations() -> Array[String] returning ["upright","tilted","flat_side"].
   - static evaluate(contract: Contract, orientation: String) -> Dictionary: {valid: bool, reason: String, support_need: float, adhesion_risk: float, stability_risk: float, estimated_material_g: int, estimated_time_s: float}. Deterministic heuristics documented in comments:
     * upright: no supports unless contract has "overhangs" flag (then 0.35); adhesion 0.15; stability 0.10; material = layers * 6; time = layers * 2.4.
     * tilted: support 0.55 (+0.2 if "overhangs"); stability 0.35; material * 1.4; time * 1.25.
     * flat_side: support 0.45; adhesion 0.55 (+0.15 if "bed adhesion"); material * 1.2; time * 1.1; invalid (reason "not printable flat") if contract has "stability" flag.
   - static risk_level(evaluation: Dictionary) -> String: "low" (max risk < 0.4), "medium" (< 0.6), "high" otherwise.
